NEON DASH

An endless 3D runner built in Unity with C#. A little robot sprints down a glowing neon highway. Switch lanes, jump and slide past obstacles, collect coins and power-ups, and go as far as you can while the game gets faster and the colours change.

Everything lives in one script (NeonDash.cs). The world, the robot, the sounds and even the music are generated by code, so there are no imported assets.

Highlights
Three lanes with jump and slide moves
Three obstacle types that each need a different move
Lives, shield, magnet, x2 score and heart pickups
Coin streak multiplier up to x4
Three modes: Chill, Normal and Insane, each with its own saved best score
Levels every 350 m, each with a new colour theme
Generated music and sound effects, with music that speeds up as you do
Keyboard, mouse and touch swipe controls
Pause, mute, floating score text, screen shake and a colour-changing track

How to run it
Requirements: Unity 2022.3 LTS (or newer) on Windows, macOS or Linux. The free Personal licence is enough.

Create a new 3D project in Unity Hub.
Copy NeonDash.cs into the project's Assets folder, or drag it into the Project window.
In the Hierarchy, right-click and choose Create Empty.
Drag the NeonDash script onto that object.
Go to Edit → Project Settings → Player → Other Settings and set Active Input Handling to Both. Unity will restart.
Make sure a Main Camera exists, then press Play.

If you cloned this repo as a full Unity project, open it from Unity Hub with Add → Add project from disk and open the scene in Assets/Scenes.


How it works
The world moves, not the player. The robot stays at the origin while obstacles, coins and scenery move toward it. This keeps numbers small and the track endless.
Own collision checks. Simple box-overlap tests on three axes replace Unity physics, which gives exact control over what hits when.
Fair patterns. Each obstacle pattern always has a way through: a safe lane, a jumpable barrier or a slide-under bar.
Object recycling. Floor lines, pillars and speed streaks that pass the camera are moved back to the far end instead of being recreated.
Procedural audio. Sound effects are sweeps and note sequences. The looping music (bass, arpeggio, kick and hi-hat) is generated by code.
State machine. The game moves between Menu, Playing and Game Over, with a separate paused flag.
Saved scores. PlayerPrefs stores the best score for each mode.
Customising it

All of these are in NeonDash.cs:
Speed and difficulty: change the modeBase and modeMax arrays.
Lives: change the modeLives array.
Level length: change distance / 350f in GameplayUpdate.
Jump feel: change JumpSpeed and Gravity.
Power-up frequency: change Random.value < 0.12f in PatternLanes.
Reset best scores: in Unity, choose Edit → Clear All PlayerPrefs.

Troubleshooting
Red errors in the Console: the script file must be named exactly NeonDash.cs.
Keys do nothing: set Active Input Handling to Both (step 5) and click inside the Game tab once.
Black screen: a camera tagged MainCamera must be in the scene.
No sound: check that Mute Audio is off in the Game tab, and that M hasn't muted the game.
